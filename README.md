# TFM_NON_CODING_NoemiToroBarrios

Repositorio asociado al Trabajo Fin de Máster:

**Evaluación de herramientas bioinformáticas para la anotación y priorización de variantes en regiones no codificantes**

## Descripción

Este repositorio contiene los scripts utilizados para la anotación, procesamiento y análisis de variantes genéticas en regiones no codificantes.

El trabajo se centra en la evaluación de distintas herramientas bioinformáticas para la predicción del impacto funcional, regulador y sobre el splicing de variantes presentes en ClinVar, utilizando el ensamblado de referencia **GRCh38**.

## Herramientas evaluadas

Las herramientas y recursos incluidos en el estudio fueron:

- CADD
- GERP++
- FATHMM-MKL
- GREEN-DB / GREEN-VARAN
- UTRAnnotator
- SpliceAI
- dbscSNV
  - ADA
  - RF
- PDIVAS
